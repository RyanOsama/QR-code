# دليل تشغيل النسخة المحمولة لنظام إدارة الدعوات والمناسبات 🎫✨

تم تجهيز النسخة التنفيذية المحمولة (Portable EXE) الخاصة بالعملاء والمستخدمين بنجاح.

---

## 📂 مكان ومسار ملف النسخة:
- **الملف التنفيذي المباشر:**
  `d:\QR code\release\EventQRManager 1.0.0.exe`
- **المجلد المفكك الجاهز:**
  `d:\QR code\release\win-unpacked\EventQRManager.exe`

---

## 🚀 كيفية استخدام وتشغيل النسخة للعميل:
1. قم بنسخ أو إرسال ملف `EventQRManager 1.0.0.exe` إلى أي جهاز كمبيوتر يعمل بنظام Windows.
2. النقر المزدوج على الملف لتشغيل البرنامج مباشرة بدون الحاجة إلى أي تثبيت مسبق أو متطلبات إضافية.
3. ستظهر شاشة تسجيل الدخول الأنيقة مباشرة للمستخدم.

---

## 🔐 تسجيل الدخول للشركات والموظفين:
- **مدير الشركة (Company Admin):**
  - يقوم بإدخال اسم المستخدم وكلمة المرور الخاصة بشركته.
  - يفتح له النظام لوحة تحكم متكاملة لإدارة المناسبات، توليد كروت QR، طباعة البطاقات، وإدارة الموظفين.
- **موظف الشركة (Employee / Scanner):**
  - يقوم بتسجيل الدخول ببياناته.
  - يتيح له النظام مسح بطاقات الحضور عبر الكاميرا والتحقق اللحظي مع إحصائيات الدخول.

---

## 🛠️ إعادة بناء النسخة في أي وقت:
يمكنك دائماً إعادة بناء النسخة بنقرة واحدة عبر تشغيل الأمر:
```bash
npm run build:win
```
