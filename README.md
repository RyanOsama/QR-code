# نظام إدارة وتأكيد دعوات المناسبات عبر QR Code
### Event Invitation & Entry Management Desktop System (Local-First Windows App)

تطبيق سطح مكتب (Windows Desktop) محلي بالكامل تم تصميمه وتنفيذه لإدارة دعوات مناسبات الزواج والفعاليات، وتوليد كروت الدعوة مع رموز QR مشفرة وفريدة، والطباعة المتعددة على ورق A4، والمسح المباشر عبر الكاميرا مع التحقق الذري لمنع الدخول المزدوج.

---

## الميزات الرئيسية

1. **Local-First بدون إنترنت:** يعمل محلياً بالكامل على جهاز المستخدم مع قاعدة بيانات SQLite مدمجة وسريعة.
2. **رموز أمان عشوائية مشفرة (Tokens):** توليد توكنات غير قابلة للتخمين (مثل: `INV-7F92A7XK29`) مع ربطها بمعرف المناسبة.
3. **منع الاستخدام المزدوج (Atomic Transactions):** فحص وتحديث حالة الدعوة وتسجيل الدخول كعملية ذرية واحدة تمنع التزامن والدخول المكرر.
4. **الطباعة الجماعية على A4:** توزيع تلقائي لـ 12 كرت في الصفحة الواحدة (3 أعمدة × 4 صفوف) مع علامات القص (Crop Marks) الدقيقة لسهولة التقطيع.
5. **ماسح الكاميرا المباشر (QR Scanner):** مسح عبر كاميرا الجهاز مع تنبيهات بصرية (شاشات خضراء/حمراء) ونغمات صوتية مركبة فورية.
6. **لوحة تحكم وإحصائيات متقدمة:** متابعة نسب الحضور وإجمالي الكروت والمتبقي، وسجل تاريخي كامل لعمليات المسح مع إمكانية التصدير كـ CSV.
7. **النسخ الاحتياطي والاستعادة:** حفظ نسخة احتياطية فورية من قاعدة البيانات واستعادتها بأمان.

---

## متطلبات التشغيل

- نظام تشغيل Windows (أو Mac / Linux)
- Node.js (v18+)

---

## أوامر التشغيل والتحقق

### تشغيل التطبيق في وضع التطوير:
```bash
npm run dev
```

### تشغيل تطبيق Electron:
```bash
npm start
```

### تشغيل الاختبارات الآلية الشاملة:
```bash
npm test
```

### اختبار النظام وقواعد البيانات فقط:
```bash
npm run test:system
```

### اختبار الـ PDF والطباعة الجماعية فقط:
```bash
npm run test:pdf
```
